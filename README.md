# 📔 AI 日记系统

> 从**整理者**到**引导者**的智能日记方案。

你只需要像聊天一样随意说出每天发生的事情，AI 会自动帮你整理成结构化的日记。需要深度思考时，AI 化身为引导者，通过提问帮你更了解自己。

## ✨ 核心特点

- 🌿 **日常模式** — 随意说，AI 整理，零负担
- 🔍 **深度模式** — AI 引导你深度反思，促进自我认知
- 📅 **按月归档** — 避免文件碎片化，清晰不杂乱
- 📊 **月/年总结** — 跳脱琐碎，看见真正的成长
- 💡 **只整理不编造** — 忠实记录你的原话原意

## 🚀 快速开始

### 1. 安装依赖

本项目基于 [WorkBuddy](https://www.codebuddy.cn/) 运行，需要安装对应的 Skill：

```bash
# 安装 ai-diary skill（推荐安装到用户级目录）
cp -r skill/ai-diary/ ~/.workbuddy/skills/ai-diary/
```

### 2. 创建你的日记目录

```plaintext
my-diary/
├── diary.config.json     # 系统配置
├── diary/                # 日记（按月归档）
│   ├── 2026-06.md
│   └── ...
└── summary/              # 总结
    ├── 2026-06.md       # 月总结
    └── 2026.md          # 年总结
```

### 3. 开始记录

对 AI 说今天发生了什么就行：

> "今天开了个需求评审会，有点烦，需求改了两次方向"

AI 会自动整理成结构化日记。

### 4. 深度反思

当想深入思考某件事时：

> "帮我深度反思一下今天的需求评审会"

AI 会通过系统性提问引导你发现自己没意识到的东西。

### 5. 总结回顾

> "帮我总结这个月"

AI 会生成月总结，包含事项汇总、心情趋势、成长亮点。

## 🧩 设计理念

### 双模式设计

| 模式 | 触发 | 特点 |
|------|------|------|
| 🌿 日常模式 | 默认 | 你随意说，AI 整理，不打扰 |
| 🔍 深度模式 | "帮我深度反思一下" | AI 通过提问引导深度思考 |

### 核心原则

1. **只整理，不编造** — AI 绝不添加用户没提到的内容
2. **有什么记什么** — 不强行凑板块，内容驱动结构
3. **日期严格分离** — 每天的记录独立，绝不混淆
4. **追问要克制** — 日常不打扰；深度模式引导，但可随时退出

### 为什么不追求"完整性"？

每天的日记不要求填满所有板块。说了什么就记什么，没提到的就跳过。**残缺的记录胜过空白的完美。**

### 为什么取消周总结？

周总结太容易流于琐碎，反而看不出真正的变化和成长。**月总结和年总结才能让你跳脱日常，看见趋势。**

## 📖 日记格式

每个月一个文件（`diary/YYYY-MM.md`），内部按天记录：

```markdown
# 2026-06

## 06-01 星期一
### 📋 今日事项
### 🌤 环境（天气/位置）
### 😊 心情
### 👥 人际关系
### 💡 感悟
### 🏷 标签

---

## 06-02 星期二
...
```

可用板块（灵活选择，有则记，无则跳过）：

| 板块 | 内容 |
|------|------|
| 📋 今日事项 | 完成了什么事情 |
| 🏃 健康 | 运动、饮食、睡眠 |
| 💻 学习 | 学到了什么 |
| 💼 工作 | 工作进展 |
| 👥 人际关系 | 和谁见了面 |
| 🌤 环境 | 天气、位置 |
| 😊 心情 | 情绪状态（1-10分） |
| 💡 感悟 | 想法、灵感、反思 |
| 📌 明日计划 | 明天想做什么 |
| 🏷 标签 | 分类标签 |

## 🔧 配置

复制 `config.example.json` 为 `diary.config.json` 并修改：

```json
{
  "storage": {
    "diary_dir": "./diary",
    "summary_dir": "./summary"
  },
  "mood": {
    "scale": "1-10"
  }
}
```
