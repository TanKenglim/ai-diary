# 📔 AI 日记系统 · 思辨版

> 从**整理者**到**引导者**，再到**思辨伙伴**的智能日记方案。

你只需要像聊天一样随意说出每天发生的事情，AI 会自动帮你整理成结构化的日记。需要深度思考时，AI 化身为引导者，通过提问帮你更了解自己。当哲学思辨自然涌现时，AI 成为你的思辨伙伴，陪你一起审视存在的命题、追踪成长的轨迹。

## ✨ 核心特点

- 🌿 **日常模式** — 随意说，AI 整理，零负担
- 🔍 **深度模式** — AI 引导你深度反思，促进自我认知
- 🧠 **思辨模式** — 当对话触及哲学命题时，AI 陪你一起思辨、论证、沉淀
- 🌱 **成长见证** — 追踪你的认知迭代、心态演变、行动轨迹
- 🤖 **自动提取** — 从日常对话中自动识别日记信号，零感知记录
- 🔒 **隐私保护** — 只记生活状态，自动过滤技术内容和敏感信息
- 📅 **按月归档** — 避免文件碎片化，清晰不杂乱
- 📊 **月/年总结** — 跳脱琐碎，看见真正的成长
- 💡 **只整理不编造** — 忠实记录你的原话原意

## 🚀 快速开始

### 1. 安装 Skill

```bash
cp -r skill/ai-diary/ ~/.workbuddy/skills/ai-diary/
```

### 2. 创建你的日记目录

```plaintext
my-diary/
├── diary.config.json     # 系统配置
├── diary/                # 日记（按月归档）
│   ├── 2026-06.md
│   └── ...
└── summary/              # 总结
    ├── 2026-06.md       # 月总结
    └── 2026.md          # 年总结
```

### 3. 开始记录

**方式一：主动陈述**

对 AI 说今天发生了什么：

> "今天开了个需求评审会，有点烦，需求改了两次方向"

**方式二：自动提取（零感知）** ⭐

不需要专门说，AI 会从日常对话中自动识别：

> 你：刚开完会，好累啊
> 你：下午和小芳喝了杯咖啡
> 你：晚上打算早点睡

AI 自动提取并暂存，随时可以查看和确认。

### 4. 深度反思

当想深入思考某件事时：

> "帮我深度反思一下今天的需求评审会"

AI 会通过系统性提问引导你发现自己没意识到的东西。

### 5. 哲学思辨

当对话自然触及哲学命题时——关于存在、意义、选择、自由——AI 会陪你一起思辨：

> "我觉得哲学离生活很遥远"

AI 不会直接给答案，而是通过追问帮你发现：你已经在思考哲学了，只是没有意识到。

### 6. 总结回顾

> "帮我总结这个月"

AI 会生成月总结，包含事项汇总、心情趋势、成长亮点、思辨沉淀。

## 🧠 设计理念

### 三模式设计

| 模式 | 触发 | 特点 |
|------|------|------|
| 🌿 日常模式 | 默认 | 你随意说，AI 整理，不打扰 |
| 🔍 深度模式 | "帮我深度反思一下" | AI 通过提问引导深度思考 |
| 🧠 思辨模式 | 对话触及哲学命题时自然激活 | AI 陪你审视存在的命题，追踪认知迭代 |

### 两种输入方式

| 方式 | 描述 | 负担 |
|------|------|------|
| 主动陈述 | 用户专门描述当天发生的事情 | 需要主动意识 |
| 自动提取 | 从日常对话中自动识别日记信号 | 零负担 ✨ |

### 核心原则

1. **只整理，不编造** — AI 绝不添加用户没提到的内容
2. **有什么记什么** — 不强行凑板块，内容驱动结构
3. **日期严格分离** — 每天的记录独立，绝不混淆
4. **追问要克制** — 日常不打扰；深度模式引导，但可随时退出
5. **隐私优先** — 只记生活状态，不记工作细节/技术内容/敏感信息
6. **思辨不灌输** — 不直接给答案，通过追问让用户自己发现
7. **成长有迹** — 追踪认知迭代和心态演变，让成长可见

### 隐私保护

自动提取时，以下内容会被**自动过滤**：

| ✅ 适合记录 | ❌ 跳过不记 |
|------------|-----------|
| "刚开完会，好累" → 记状态 | 会议具体内容、决策、数据 |
| "和小芳吃了饭" → 记社交 | 聊了什么私密话题 |
| "今天状态不错" → 记心情 | 具体技术方案、代码逻辑 |
| "去跑了步" → 记运动 | 公司内部信息、商业机密 |

**用户控制：**
- "这段不要记" — 停止记录当前话题
- "今天不记日记" — 当天暂停自动提取
- "帮我看看今天记了什么" — 查看当天已提取的内容

### 为什么不追求"完整性"？

每天的日记不要求填满所有板块。说了什么就记什么，没提到的就跳过。**残缺的记录胜过空白的完美。**

### 为什么取消周总结？

周总结太容易流于琐碎，反而看不出真正的变化和成长。**月总结和年总结才能让你跳脱日常，看见趋势。**

## 📖 日记格式

每个月一个文件（`diary/YYYY-MM.md`），内部按天记录：

```markdown
# 2026-06

## 06-01 星期一
### 📋 今日事项
### 🌤 环境（天气/位置）
### 😊 心情
### 👥 人际关系
### 💡 感悟
### 🧠 思辨
### 🌱 成长标记
### 🏷 标签

---

## 06-02 星期二
...
```

可用板块（灵活选择，有则记，无则跳过）：

| 板块 | 内容 |
|------|------|
| 📋 今日事项 | 完成了什么事情 |
| 🏃 健康 | 运动、饮食、睡眠 |
| 💻 学习 | 学到了什么 |
| 💼 工作 | 工作进展 |
| 👥 人际关系 | 和谁见了面 |
| 🌤 环境 | 天气、位置 |
| 😊 心情 | 情绪状态（1-10分） |
| 💡 感悟 | 想法、灵感、反思 |
| 🧠 思辨 | 哲学层面的思考与论证 |
| 🌱 成长标记 | 认知迭代、心态演变、行动突破 |
| 📌 明日计划 | 明天想做什么 |
| 🏷 标签 | 分类标签 |

## 🧠 思辨模式详解

### 什么是思辨模式？

思辨模式不是"教你哲学"，而是当你的对话自然触及存在、意义、选择、自由等命题时，AI 陪你一起审视这些命题，帮你把模糊的直觉变成清晰的思考。

### 激活方式

思辨模式不需要显式触发。当对话中出现以下信号时，AI 会自然进入思辨状态：

- 对某个现象感到困惑，说不出为什么
- 触及"存在"、"意义"、"选择"、"自由"等命题
- 对某个哲学观点产生共鸣或质疑
- 感到迷茫，不知道自己想要什么
- 发现自己的行为和信念之间存在矛盾

### 思辨原则

1. **不灌输** — 不直接给答案，通过追问让用户自己发现
2. **不评判** — 不评判用户的想法对错，只帮其澄清
3. **不脱离** — 始终从用户的具体经验出发，不空谈理论
4. **可沉淀** — 思辨的结果可以写入日记，成为成长的见证

### 思辨记录格式

```markdown
### 🧠 思辨
**命题**：哲学离生活很遥远吗？
**困惑**：哲学命题很震撼，但感觉对日常生活没有启发
**对话过程**：
- 发现困惑来自"实用主义 + 迷茫"
- 领悟"我们必须想象西西弗是幸福的"
- 核心洞见：意义不是先于行动被发现的，而是在行动中涌现的
**沉淀**：先推起来，意义才会出现。石头就在那里，推就是了。
```

## 🌱 成长追踪

### 成长标记类型

| 类型 | 含义 | 示例 |
|------|------|------|
| 认知迭代 | 对某件事的理解发生了改变 | "以前觉得哲学无用，现在发现生活中处处是哲学" |
| 心态演变 | 情绪或态度的转变 | "从迷茫转向行动导向" |
| 行动突破 | 做了以前不会做的事 | "第一次主动记录哲学思考" |
| 自我发现 | 对自己有了新的认识 | "发现自己其实是实用主义者" |

### 成长追踪方式

AI 会在以下时机追踪成长：
- 月/年总结时，对比前后日记，识别成长轨迹
- 思辨对话后，标记认知迭代
- 用户主动说"我发现自己变了"时

## 🔧 配置

复制 `config.example.json` 为 `diary.config.json` 并修改：

```json
{
  "storage": {
    "diary_dir": "./diary",
    "summary_dir": "./summary"
  },
  "input": {
    "modes": {
      "active": { "enabled": true },
      "auto_extract": {
        "enabled": true,
        "privacy_filter": true
      }
    }
  },
  "mood": {
    "scale": "1-10"
  },
  "philosophy": {
    "enabled": true,
    "auto_detect": true,
    "record_enabled": true
  },
  "growth_tracking": {
    "enabled": true,
    "track_cognitive_change": true,
    "track_mood_evolution": true,
    "track_action_breakthrough": true
  }
}
```
